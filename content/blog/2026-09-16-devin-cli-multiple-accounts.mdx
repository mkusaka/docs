## まとめ

- Devin CLIは`XDG_DATA_HOME`配下の`devin/credentials.toml`に認証を書くので、`XDG_DATA_HOME`だけ切り替えれば認証を分離できる
- `devin.org_id`は`~/.config/devin/config.json`に入るので、config.jsonだけ`--config`でプロファイル別に指定する
- `XDG_CONFIG_HOME`は`~/.config`のままにして、`~/.config/devin/`配下のskills・AGENTS.md・sessions.dbなどを共有する
- `atuin`や`gh` extensionsなど、`XDG_DATA_HOME`を変えると副作用が出るものはsymlinkで元の場所に戻す

## ファイル配置

| 種別                      | パス                                    | profile間で          |
| ------------------------- | --------------------------------------- | -------------------- |
| 認証                      | `$XDG_DATA_HOME/devin/credentials.toml` | 分離する             |
| MCP OAuth                 | `$XDG_DATA_HOME/devin/mcp/oauth/`       | 分離される           |
| sessions/transcripts/logs | `$XDG_DATA_HOME/devin/`                 | 分離する             |
| 設定（org_id含む）        | `~/.config/devin-<profile>/config.json` | `--config`で切り替え |
| グローバルskills等        | `~/.config/devin/` 配下                 | 共有                 |
| atuin履歴                 | `~/.local/share/atuin`                  | symlinkで共有        |
| gh extensions             | `~/.local/share/gh`                     | symlinkで共有        |

## profile切り替えwrapper

`~/bin`が`/opt/homebrew/bin`よりPATH前方にある前提で、`~/bin/devin`を置く。

```sh
#!/bin/sh
# DEVIN_PROFILE=<name> devin [...]
# devin の auth/state を profile 分離する wrapper。
#   default 以外: XDG_DATA_HOME=~/.local/share/devin-<name>
#                 config.json は ~/.config/devin-<name>/config.json
#                 XDG_CONFIG_HOME は ~/.config のまま
#   atuin, gh など共有したい XDG data は symlink
set -eu

self="$(cd "$(dirname "$0")" && pwd -P)/$(basename "$0")"
real="$(type -aP devin | grep -Fvx "$self" | head -n 1)"

case "${DEVIN_PROFILE:-default}" in
  default)
    exec "$real" "$@" ;;
  *)
    export XDG_DATA_HOME="$HOME/.local/share/devin-$DEVIN_PROFILE"
    mkdir -p "$XDG_DATA_HOME"

    for dir in atuin gh; do
      if [ ! -e "$XDG_DATA_HOME/$dir" ]; then
        mkdir -p "$HOME/.local/share/$dir"
        ln -s "$HOME/.local/share/$dir" "$XDG_DATA_HOME/$dir"
      fi
    done

    mkdir -p "$HOME/.config/devin-$DEVIN_PROFILE"
    exec "$real" --config "$HOME/.config/devin-$DEVIN_PROFILE/config.json" "$@" ;;
esac
```

```bash
devin                              # 今まで通り
DEVIN_PROFILE=work devin auth login  # 別アカウントでログイン
DEVIN_PROFILE=work devin auth status
```

## 初回セットアップ・移行

既存のprofileディレクトリ（例：`devin-personal`）を新しい構成に合わせる。

```bash
# config.jsonをプロファイル直下に移動
mv ~/.config/devin-personal/devin/config.json ~/.config/devin-personal/config.json

# atuinを共有
rm -rf ~/.local/share/devin-personal/atuin
ln -s ~/.local/share/atuin ~/.local/share/devin-personal/atuin

# gh extensionsを共有
ln -s ~/.local/share/gh ~/.local/share/devin-personal/gh
```

`~/.config/devin-personal/devin/`に残る`AGENTS.md`・`skills`・`ponytail-hook.js`のsymlinkは不要になる。`devin`は`~/.config/devin/`を直接読む。

## 設定とsessions

- `config.json`だけ`~/.config/devin-<profile>/config.json`に置く。`devin.org_id`はここに書き戻される
- `~/.config/devin/`配下の`AGENTS.md`・`skills`・`sessions.db`は全profileで共有
- sessions.dbは複数profileから同時アクセスすると`database is locked`になり得る。WALなのでretryすれば通る

## 注意点

- `XDG_CONFIG_HOME`はwrapperで上書きしない。`--config`だけで`config.json`の場所を変える
- `atuin`や`gh`は`XDG_DATA_HOME`に従うので、symlinkを忘れると履歴・extensionsがプロファイル別になってしまう
- `mise`や`uv`も`XDG_DATA_HOME`に従う。プロファイル別にしたくないなら同様にsymlinkするか、`MISE_DATA_DIR`・`UV_TOOL_DIR`など個別の環境変数で固定する
- `XDG_DATA_HOME`を切り替えても`devin`のsessions/transcriptsはプロファイル別になる。履歴を共有したい場合は`~/.local/share/devin/cli`や`summaries`をsymlinkする
- `read_config_from`はprofile側に引き継がれない。main側でproviderを絞っている場合はprofile側configにも書く
